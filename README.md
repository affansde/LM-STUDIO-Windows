# LM STUDIO

**LM STUDIO** is the local LLM desktop: lm studio ai, lm studio bionic, download lm studio, chat and agent.

## How to use
1. Download v0.4.24.
2. Extract `LM-STUDIO.zip`.
3. Run LM Studio.
4. Download a model. Chat or start Bionic.
